# Voicestack reach-out

The external bridge currently admits ONLY the current technical chief session,
resolved from its existing pointer. This kit does not modify that bridge, create
another sender or impersonate the technical chief. See the inventory's verified
source interface and limitations, not a new fabricated API.

Another domain sends an attributed `review` handoff to the technical owner using
existing a2a. The owner decides under the principal's permissions whether any
reach-out is warranted. A handoff/receipt is not permission or proof of contact;
no automatic phone message, notification, schedule or new-send acknowledgement.
Uncertain delivery stays unresolved. Check the operator's existing Fleet registry
before adopting a service; avoid duplicate adoption. This grants no permission
to probe, start or install services. No CLI/socket call in fixtures.
