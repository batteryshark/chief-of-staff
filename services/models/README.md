# Model policy

The technical owner's installed `models.md` is authoritative. `models.md` at the
repository root is only the legacy create-once seed. Technical chief composition
uses `technical-chief.md` without changing its words; technical leads retain the
existing profile policy. Scoped profiles reference `$CHIEF_BRIEF_DIR/models.md`
(default `$HOME/.chief-of-staff/models.md`) read-only, never copy or edit it.
Paid model permission remains outcome/project-specific. Standalone leads may be
given a policy explicitly but do not require any chief memory.
