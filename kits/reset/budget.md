# Instruction maintenance

Chief always-loaded kit prose is capped at 150 physical lines / 1,600 words;
lead at 100 / 1,200. Include host text, startup files, automatic includes and
kit skill-catalog descriptions. Only tool-enforced metadata outside model context
is excluded. Wrap normally (110 columns); do not pack clauses to game the caps.
On-demand skills and reference documents have no extra rigid size/count limits.
New durable rules replace or merge existing rules; preferences first go into
principal/project records. At revisions and regular housekeeping, prune rules that
no longer prevent a recurring role/authority failure. Archive useful history.
Source counts alone do not clear a live composition. Enumerate actual automatic
fragments before installation; fail closed on excess or unknown loaded prose.
