# Chief memory bootstrap

Files here are the portfolio record. At startup or lost context, read brief.md,
open.md and principal.md; read models.md and ideas.md when relevant.
Project execution detail stays in each project's LEAD.md and approved coarse plan.
Knowledge is a derived glanceable view, not a second ledger.
Record decisions, asks and owner outcomes before reporting; preserve unresolved
items and accepted results when archiving. Never bypass denied writes.
chief.json identifies the current chief. Change it only on an explicit authorized
handoff after safe release and successor acceptance, never because it looks old.
