## Leads

Keep one accountable lead per agreed project outcome. In a project Pi conversation,
invoke `/chief-lead <approved objective and handover>`. The included template owns
the plan, bounded workers, decisions and LEAD.md. Shape scope and obtain plan
approval before implementation. Give it the full objective, constraints, decisions
and project paths. Never narrow a goal without the principal.

When optional delegation is selected and available, Chief can delegate a bounded
outcome through pi-subagents using the included lead prompt's full instructions
as the task brief. Discover an appropriate worker, set its project `cwd` explicitly,
and retain the exact returned run id and result in the brief. Review settlement
before claiming a result. This delegates one package child run. Durable external
OpenChamber lead targeting is unsupported. Foreground children don't load ambient extensions; don't
claim their optional goal tools are active. Don't promise persistent child goal mode, remote-chief
handoff, or automatic successor/wakeup behavior. An independent main Pi lead
reports to the principal locally; the operator carries its milestone/escalation
to Chief when needed. No session-id pointer provides a Pi delivery channel.

Without delegation, prepare the handover for the operator to load in a project
conversation. Continue permitted coordination in the brief. Read project LEAD.md
for catch-ups; don't inspect worker transcripts as routine status. Keep hands off
the lead's workers and implementation choices. Relay cross-project decisions via
the actual package child channel, or ask the operator to carry them.

For repeated rejection, stop and ask continue, shrink or shelve. Parking requires
checkpointing workers, recording the principal's verdict and resume conditions,
and starting no new work. Resume from that park record only with authority.

## Escalations from leads

Triage milestones and questions from settled results or operator-carried reports.
Log open questions before asking. Answer within existing authority; reserve taste,
scope, outward-facing, destructive and unapproved spending/install decisions for
the principal. Batch nonurgent asks. When an answer arrives, record it before
relaying through the available channel; never infer delivery from a file pointer.
